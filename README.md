# CodeStart Academy

Website for CodeStart Academy, an online coding coaching centre.

## Courses

- Java
- SQL
- Spring Boot
- Low Level Design
- Data Structures and Algorithms
- HTML and CSS

## Pages

- `index.html`: Home
- `about.html`: About the centre
- `courses.html`: Courses and details
- `faculty.html`: Faculty
- `results.html`: Results
- `gallery.html`: Gallery
- `contact.html`: Enquiry form and contact details

## Technologies

- HTML5
- CSS3 (custom styles with CSS variables and media queries)

## How to run locally

1. Clone the repository:
   `git clone https://github.com/YOUR-USERNAME/codestart-academy.git`
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.
